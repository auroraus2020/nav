# AURORAUS 导航

## 项目简介

AURORAUS 导航是一个**单文件纯静态**的网址导航主页，把科研、学习、生活常用的 276 个网站按 17 个分类编排成卡片墙，用来替代浏览器默认主页。打开即用、零后端、零构建、可离线，所有个人配置（壁纸、主题、分类顺序、自定义站点）都存在浏览器本地，并能一键导出 JSON 分享或迁移到别的电脑。

线上地址：<https://nav.auroraus.cn>

## 功能特性

- **分类卡片墙**：17 个内置分类 / 276 个站点（综合导航、学术检索、AI大模型、北航网站、导航网站、技术与交流、翻译工具、学习提升、效率提升、效率工具、地图天气、影音娱乐、学习教程、航空与科普、镜像网站、传统文化、云服务器）。
- **大搜索框**：24 个内置搜索引擎（必应、百度、谷歌、Yandex、谷歌学术、GitHub、知乎、B站、百度地图…）+ 自定义引擎（用 `%s` 占位）。
- **本页筛选**：输入关键词不回车只筛选当前页卡片，回车才跳转搜索。
- **分类排序双模式**：`按使用时间排序`（点过的分类自动置顶）或 `固定顺序`（顺序由你在设置里用 ↑↓ 手动排定，点击不改变顺序）。
- **四路壁纸**：在线风景壁纸（`assets/wp_*.jpg` 轮换）/ 默认壁纸 / 自定义网络壁纸 / 本地图片壁纸（可选择随 JSON 一起导出）。默认使用**默认壁纸**。
- **主题**：浅色 / 深色。
- **右侧快捷工具栏**（电脑端）：在线 WPS、微信文件传输、计算器、画图、工具箱，以及待办事项、记事本、番茄钟、单位换算四个悬浮窗；还可用编辑器添加任意自定义工具。
- **配置导入导出**：全部设置导出为 JSON，支持本地文件或网络 URL 导入；`configs/default_recommended.json` 为推荐配置预设。
- **可视化配置编辑器**：图形化管理站点、分类、搜索引擎、快捷工具与页面设置。
- **使用帮助**：`help/` 目录下的完整中文图文说明。

## 快速启动

### 环境要求

- 运行：任意现代浏览器（Chrome / Edge / Firefox / Safari）。**无任何运行时依赖**。
- 开发期校验（可选）：Python 3.8+；如需跑 JS 语法检查与 UI 行为测试，另需 Node.js 与 Chrome。

### 安装与配置

无需安装、无需环境变量、无凭据。

```powershell
git clone <本仓库地址>
cd Auroraus导航网页
```

### 本地运行

```powershell
# 方式一：直接双击 index.html（file:// 即可正常工作）
start index.html

# 方式二：起本地静态服务（推荐用于调试相对路径）
python -m http.server 8080
# 然后浏览器打开 http://127.0.0.1:8080/
```

修改后建议跑以下校验：

```powershell
python tools/verify_site_integrity.py   # 分类计数 / 点名站点 / 新分类登记
python tools/verify_config_sync.py      # index.html 与 config-editor/data.js 一致性
python tools/check_js_syntax.py         # 内联脚本语法
python tools/run_ui_tests.py            # 无头 Chrome 行为测试（期望 PASS=61 FAIL=0）
```

## 部署方式

纯静态站点，**把整个目录上传到任意静态托管即可**（Nginx、Apache、GitHub Pages、Cloudflare Pages、对象存储均可），无需后端与构建步骤。

- 入口文件：`index.html`
- 需一并上传的目录：`assets/`（图标与壁纸）、`configs/`、`config-editor/`、`help/`
- 无服务端配置要求；若托管平台默认不给 `.gif`/`.jpg` 正确的 MIME，请确保静态资源按扩展名返回。
- 回滚：恢复上一版本目录即可（本仓库在 `.backup/` 内维护本地 Git 备份）。

## 常见问题（FAQ）

- **改了主页卡片，编辑器里还是旧的？** 站点数据有两份：`index.html` 与 `config-editor/data.js`。改一处必须同步另一处，然后跑 `python tools/verify_config_sync.py` 确认。
- **编辑器里保存了，主页刷新没变化？** 硬刷新（`Ctrl` + `F5`）；确认不是隐身窗口（隐身模式的 localStorage 相互隔离）。
- **导入 JSON 后新引擎/新分类看不到？** 自定义引擎与自定义分类默认可能处于隐藏状态，去「设置 → 搜索引擎显示 / 分类显示」把它点亮。
- **分类顺序老是跳？** 当前是「按使用时间排序」模式。想固定，去「设置 → 分类排序模式」选 **固定顺序**，再用 ↑↓ 手动排。
- **背景变回默认图了？** 默认壁纸是新的默认值；若你此前一直在用「在线风景壁纸」且从未手动切换过，会被自动切到默认壁纸一次。想换回来：设置 → 壁纸来源 → 在线风景壁纸（或自定义/本地图片）。
- **某些国外站点打不开？** 属网络环境问题（本机网络对部分境外域名存在 DNS 污染），不是导航页的问题；请使用代理。
- **多个站点/分类的技术细节与维护约定**：见 `Agent MD/AGENTS.md`。
