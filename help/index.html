一、打开网站的第一眼

在浏览器打开 https://nav.auroraus.cn，你会看到：

  • 大搜索框 — 页面正中间，输入关键词就能搜
  • 搜索引擎选择栏 — 搜索框下面一排按钮，每个按钮代表一个搜索引擎
  • 常用站点 — 你点得最多的网站，会自动出现在搜索框下面
  • 分类导航卡片 — 按"综合导航""学术检索""AI大模型"等分类排列的网站卡片
  • 左侧侧边栏（电脑）或 底部Tab栏（手机）— 快速跳转到不同分类
  • 右侧快速工具栏（电脑）— 一排竖着的图标，一键打开在线WPS、微信传输、计算器、画图等常用网站
🖱️ 打开一个网站：直接点任意卡片，网站在新标签页打开，本页保持不变。
📂 收起/展开一个分类：点分类标题（比如"学术检索"），下面所有卡片会收起或展开。鼠标点一下就行。
🔍 搜索本页的网站：在搜索框输入关键词（比如输入"知乎"），页面会只保留名称或描述包含"知乎"的卡片。按 Esc 键恢复到全部显示。
📏 长文本自适应：输入长内容时搜索框会自动变高并自动换行（最多 10 行，超出后框内滚动），文本始终可见；Enter 直接搜索、Shift+Enter 换行。清空输入请按 Esc。
🕒 右上角那个玻璃小块：两行——第一行「🌐 需 VPN 显示/隐藏 + 🌙 主题切换」，第二行「日期 · 星期 · 本地时间 + 🌤️ 天气按钮（会自动显示关注地当前的天气图标）」。右下角还有一行很浅的壁纸图源说明（点它跳 Zoom Earth 实时卫星图）。详见「二十一」。
💡 常用站点区：你每点一个网站卡片，系统就记一次数。点得最多的几个会自动出现在"常用站点"区。不需要你特意收藏。

二、搜索引擎怎么用

搜索框不只是用来过滤导航卡片的——它更是一个能切换多种搜索引擎的搜索聚合器。

✅ 默认勾选哪几个引擎

默认只显示这 14 个：必应、谷歌、百度、秘塔AI（metaso）、Perplexity、Yandex、搜狗知乎、搜狗微信、Quora、Reddit、谷歌学术、微软学术、译中、译英（百度固定排第三，紧跟必应、谷歌）；其余（搜狗、谷歌学术②、XMOL、北航外文、百度学术、抖音、小红书、哔哩哔哩、知乎、微博、GitHub、百度地图、WikiHow、Sci-Hub、KipHub、维基百科）默认隐藏，想要哪个去设置面板 → "搜索引擎显示"点成蓝色即可。

新增的 🧠秘塔AI（metaso.cn，国产 AI 搜索，免登录即可用）、🔎Perplexity（perplexity.ai，AI 答案引擎，紧挨在秘塔后面）与 🟠Reddit（Reddit 站内搜索）已加入引擎栏；都支持回车直搜。

🔀 切换搜索引擎（三种方式）

方式一：鼠标点 — 点搜索框下面你想用的引擎就行了，选中的会高亮。
方式二：按 Ctrl / Alt 键 — 单独按一下 Ctrl（不要同时按别的），引擎按搜索框下面的显示顺序切到下一个；单独按一下 Alt，切到上一个（到头会循环）。只会在你开启的那些引擎之间轮换。
方式三：按 F1 ~ F12 — F1 选搜索框下面第一个可用引擎，F2 选第二个……也是按显示顺序。

🔎 执行搜索

在搜索框里打好你要搜的关键词 → 按 回车键 或点旁边的"搜索"按钮 → 浏览器开新标签页用你选的引擎搜索。

提交搜索后，输入框里的关键词会自动清空（顶部悬浮搜索条一起清空），页面上的筛选也同时复位，方便你接着搜下一个词——想换关键词直接打就行，不用手动删。

网页往下滚一段距离后，页面顶部会浮出一个悬浮搜索条，显示当前选中的搜索引擎名字，随时可以搜，不用滚回顶部。

🌐 需 VPN 站点开关在右上角（和主题切换 🌙 并排）：显示＝一直显示（站点与全部引擎都在，需 VPN 的带角标）；隐藏＝一直隐藏（需 VPN 的站点与 谷歌 / Perplexity / Quora / Reddit / 谷歌学术 等引擎立刻从页面上消失）。点一下立即生效，引擎栏与站点列表同步更新。想用「自动判断」仍可在设置面板里选。
🔬 高级搜索 = 搜索框旁边的小浮层（点搜索框右侧的 🔬，面板就贴在搜索框下方弹出，不占页面高度、也不在设置窗口里；再点一次或点 ✕ 收起）。只对 必应 / 百度 / 谷歌 / Yandex 生效，其他引擎（搜狗、秘塔、Perplexity、知乎、翻译等）完全不受影响。四个引擎各自用自己的语法，不是一套硬套：
① 关键词分隔：空格、英文逗号/分号、中文逗号/分号、顿号都行（a，b;c、d e → 5 个词）；
② 包含全部关键词（按 AND 拼）/ 包含任意一个（自动拼 (A OR B)）/ 不包含（自动加 -）/ 整句精确匹配（加引号）；
③ 关键词位置：网页任何位置 / 仅在标题 / 仅在网址——位置前缀会逐词套用（intitle:a intitle:b、(intitle:a OR intitle:b)），不会再出现必应/谷歌不认的 intitle:(A OR B) 写法；Yandex 用 title: / url:；
④ 站内搜索（域名 → site:）、文档格式（filetype:pdf，Yandex 用 mime:pdf）；
⑤ 时间范围：谷歌 tbs=qdr:d|w|m|y、必应 qft=filterui:age-lt…（按分钟，单条过滤不带前导 +，否则会被解码成空格失效）、百度 gpc=stf=…|stftype=2、Yandex 用 date:YYYYMMDD..YYYYMMDD 操作符；自定义时段：谷歌 tbs=cdr:1,cd_min:…、百度 gpc 的起止时间戳、Yandex date: 区间（必应没有自定义时段，会退回按天预设）；
⑥ 每页条数：谷歌 num、必应 count、百度 rn（Yandex 无此参数，改用 noreask=1）。
启用且带条件时，🔬 会高亮，鼠标悬停直接列出当前带了哪些条件。
🎯 两种搜索模式（设置面板 → 🎯 搜索模式）：
全搜索（默认）：边打边筛选本页网站、自动展开有匹配的分类，回车/点「搜索」再用引擎联网搜。
专注搜索：搜索框只负责联网搜索——输入时不再匹配本站网站、也不会自动展开下方分类；导航的展开 / 收起保持你现在的样子（不替你收起，也不替你展开），所以你展开着打关键词也不会被合上。
⌨️ 搜索后输入框里的字留不留（设置面板 → 🎯 搜索模式 → 「搜索后保留输入 / 搜索后清空输入」）：
保留输入（默认）：回车或点「搜索」后，关键词仍然留在输入框里，方便改两个字再搜、或换引擎对比同一句话——不用重新打一遍。
清空输入：每次搜索后输入框自动清空并重新聚焦，适合「搜完立刻换下一个词」的用法。
小提醒：想临时清空，按 Esc 就会清空并收起筛选；这个开关只影响「点搜索/按回车」之后的行为。
💡 怎么让某个引擎出现/消失：去设置面板 → "搜索引擎显示"，点它对应的圆角按钮。蓝色 = 显示，灰色 = 隐藏。新导入的自定义引擎默认是隐藏的，记得去打开。
🌐 没有科学上网时会自动少几个：默认勾选的 14 个里，谷歌、Perplexity、Quora、Reddit、谷歌学术 需要科学上网。当"需 VPN 站点的显示方式"判定为当前上不了外网时，这 5 个会自动从引擎栏里消失（其余 9 个不受影响，仍可正常搜索）；有 VPN 时会自动回来。若此刻正选着被隐藏的引擎，会自动切回必应。不想让它自动判断，可在设置面板把显示方式改成"一直显示"或"一直隐藏"。

自定义工具

你可以在配置编辑器中添加任意数量的自定义快捷工具，每个工具可以设置：

  • 图标 — 任意emoji表情
  • 名称 — 鼠标悬停时显示的提示文字
  • 网址 — 点击时打开的链接
  • 启用/禁用 — 控制某个工具是否显示
怎么添加自定义工具：打开设置 → 点 🖊️ 编辑器 → 切换到 🔗 快捷工具 标签页 → 在这里管理你的自定义工具 → 点 💾 保存。

全局开关

在编辑器的快捷工具页面，可以用全局开关一键启用或禁用整个右侧工具栏。禁用后所有图标都会消失。

💡 为什么不在主页设置里管理？快捷工具的自定义配置项较多（图标、名称、URL、启用状态），放在编辑器里用表格管理更方便。导出/导入配置时会自动包含自定义工具。

📋 待办事项

在右侧工具栏最下方有一个📋图标，点击后会弹出一个半透明悬浮窗，可以用它来管理你的待办事项。

功能说明

  • 添加待办 — 在输入框中输入内容，按回车或点"添加"按钮即可新增待办
  • 切换状态 — 点击待办项前面的方框，可以在"未完成"和"已完成"之间切换
  • 筛选查看 — 顶部有"全部""未完成""已完成"三个标签页，方便分类查看
  • 删除待办 — 鼠标悬停在待办项上，右侧会出现 × 删除按钮
  • 重要性等级 — 每条待办支持设置三个等级：● 一般 / ● 重要 / ● 紧急，分别以蓝、橙、红三色圆点标记，点击圆点即可循环切换
  • 截止日期与倒数日 — 可为待办设置截止日期，待办项右侧会显示距离截止日的倒数天数（如"剩3天""已过期2天"），过期任务以红色高亮提醒
  • 自动清理 — 已完成超过2天的待办事项会被自动清除，不再显示
  • 拖拽移动 — 按住悬浮窗标题栏，可以把它拖到页面上任意位置
  • 关闭窗口 — 点击标题栏右侧的 ✕ 按钮即可关闭（不会自动消失，只有手动关闭）

导入/导出

悬浮窗标题栏有📤导出和📥导入按钮：

  • 📤 导出 — 将所有待办事项导出为 .json 文件，方便备份或迁移
  • 📥 导入 — 选择之前导出的 .json 文件，恢复待办数据
💡 数据存储：待办数据保存在浏览器的本地存储中，不会上传到任何服务器。清除浏览器缓存或更换浏览器会导致数据丢失，建议定期导出备份。

📝 记事本

在右侧工具栏中有一个📝图标，点击后会弹出一个Markdown 记事本悬浮窗，可以随时随地记录笔记。

功能说明

  • 编辑 / 预览双模式 — 顶部有"编辑"和"预览"两个标签页切换。编辑模式下自由书写 Markdown 文本，预览模式下实时渲染为格式化的富文本
  • 📥 导入 .md 文件 — 点击标题栏的 📥 按钮，可从本地选择 .md 或 .txt 文件导入到编辑区
  • 📤 导出 .md 文件 — 点击标题栏的 📤 按钮，将当前笔记内容导出为 .md 文件下载保存
  • 🗑️ 清空内容 — 点击标题栏的 🗑️ 按钮可一键清空所有笔记内容（操作前有确认提示）
  • 拖拽移动 — 按住悬浮窗标题栏，可以将记事本拖到页面上任意位置
  • 自由调整大小 — 拖拽悬浮窗右下角的三角形手柄，可以自由拉伸窗口的宽度和高度
💡 数据存储：笔记内容保存在浏览器本地存储中，不会上传到任何服务器。在配置编辑器中导出/导入全局配置时会一并包含笔记数据。建议定期导出 .md 文件备份重要笔记。

🍅 番茄钟

在右侧工具栏中有一个🍅图标，点击后会弹出一个专注计时悬浮窗，帮你用番茄工作法管理专注时间。

功能说明

  • 三种模式 — 专注 25 分钟 / 短休 5 分钟 / 长休 15 分钟，可按需切换
  • 圆形进度环 — 悬浮窗中央有一个圆形进度环，实时显示剩余时间
  • 开始 / 暂停 / 重置 — 三个按钮控制计时流程，可随时暂停或重置当前计时
  • 自动统计 — 每完成一次专注，自动累计：今日专注次数 + 累计分钟数
  • 长休自动切换 — 每完成 4 次专注后，自动切换为长休模式，劳逸结合
  • 标签页标题提示 — 专注完成时，浏览器标签页标题会同步提示，方便你在其他标签页时也能看到
  • 拖拽移动 — 按住悬浮窗标题栏，可以把它拖到页面上任意位置
  • 自由调整大小 — 拖拽悬浮窗右下角的三角形手柄，可以自由拉伸窗口的宽度和高度

导入/导出

悬浮窗标题栏有📤导出和📥导入按钮：

  • 📤 导出 — 将番茄钟统计数据导出为独立 .json 文件，方便备份或迁移
  • 📥 导入 — 选择之前导出的 .json 文件，恢复番茄钟数据
💡 数据存储：番茄钟数据保存在浏览器的本地存储中，不会上传到任何服务器。在配置编辑器中导出/导入全局配置时会一并包含番茄钟数据。建议定期导出备份。

📐 单位换算

悬浮窗式单位换算工具，无需打开外部网站即可快速换算。特别覆盖航空航天常用美制/英制单位（psi/ksi/lbf/slug/ft²/nmi/Mach等）。

  • 十四大类换算：
    • 长度：m/km/cm/mm/μm/nm/inch/ft/yd/mile/nmi(海里)/mil(密耳)/光年
    • 质量：kg/g/mg/t/lb/oz/slug(斯勒格)/grain/US ton/long ton/ct
    • 温度：℃/℉/K/°R(兰氏度)
    • 角度：°/rad/grad/角秒/角分/转/mrad

十、编辑器怎么和主页同步？

很多用户问：这是静态页面，编辑器改的东西怎么跑到主页上去的？

答：通过浏览器的 localStorage（本地存储）。

  • 编辑器保存时 → 把配置写入浏览器的 localStorage
  • 主页加载时 → 从浏览器 localStorage 读取配置并渲染
  • 因为是同一个域名（nav.auroraus.cn），两个页面共享同一份 localStorage
  • 不需要服务器、不需要数据库、不需要API — 纯前端就搞定了
操作流程：编辑器改 → 💾保存 → 打开主页刷新 → 生效 ✅
⚠️ 注意：如果你清除了浏览器的"网站数据"，配置会丢失。建议定期点 📤 导出JSON 做备份。

十一、通过JSON给已有分类增删站点

不需要改网页代码！只要在 JSON 配置文件里加两个字段：

✚ 往已有分类里添加站点

在 JSON 文件里加一个 addSites 字段，格式是 { "分类ID": [站点信息...] }。

比如，在"综合导航"分类里加两个新网站，JSON 文件这样写：

{
  "addSites": {
    "cat-general": [
      {"name":"V2EX","url":"https://www.v2ex.com","desc":"创意工作者社区","icon":"V","iconColor":"blue"},
      {"name":"Product Hunt","url":"https://www.producthunt.com","desc":"新产品发现平台","icon":"P","iconColor":"orange"}
    ]
  }
}

导入后，这两个新卡片就会直接出现在"综合导航"分类的末尾。再次导入同一个 JSON 不会重复添加。

✖ 从已有分类里移除站点

在 JSON 文件里加 removeSites 字段，填上分类ID和要移除的站点名称列表。

比如，把"技术交流"分类里的"V2EX"和"掘金"两个站点隐藏掉：

{
  "removeSites": {
    "cat-tech": ["V2EX", "掘金"]
  }
}

站点名称必须和页面上显示的完全一致（区分大小写）。

💡 addSites 和 removeSites 可以和 categories、engines、settings 写在同一个 JSON 文件里，一次导入全部生效。导出时这些信息也会一并导出。

模式行为

十七、需 VPN 站点与三种显示方式

搜索引擎仍是原来那一排标签按钮，点一下切换、按回车搜索。

有些站点（Google、YouTube、X、Quora、维基百科等）需要科学上网才能访问。导航页会给这类站点打上一个小角标 VPN。最快的切换方式在首页搜索框正下方：🌐 需 VPN 站点 · 显示 / 隐藏两个小按钮，点一下立即生效（引擎栏与站点列表同步），不用进设置。三种模式（设置面板 → 🌐 需 VPN 站点的显示方式）说明如下：

方式行为
一直显示（默认）所有站点与搜索引擎都显示，需 VPN 的带小角标提示。不做任何探测，打开就是完整列表（首页快捷按钮点「显示」就是它）。
自动判断页面加载后会在后台探测 google.com 与 quora.com 的图标图片（各最多等 1.2 秒，结果缓存 10 分钟）。两个都失败才隐藏需 VPN 的站点；只要有一个成功、或探测本身异常，都按「显示」处理，避免误杀。用图片加载判断而非 HTTP 状态，是因为部分网络的拦截页会返回假 200，图片解码可识破。按 F12 可在控制台看到探测结果。
一直隐藏需 VPN 的站点与对应搜索引擎一律不显示，不做任何探测（最快，首页快捷按钮点「隐藏」就是它）。

这三种模式是互斥单选，任何时候只有一个生效；首页快捷按钮只会在「一直显示 / 一直隐藏」之间切换。隐藏后：某个分类里的站点全被隐藏时，该分类会自动收起；带 VPN 属性的搜索引擎（谷歌、Perplexity、Quora、Reddit、谷歌学术、Sci-Hub、维基百科）也会从引擎栏里消失，若当前正选着它，会自动切回第一个可用引擎。

本轮（最新一次全站实测）新补的标记：APKPure、APKMirror、APKCombo、Uptodown、F-Droid、APKMonk（安卓 APK 镜像，国内直连超时）、V2EX、Hacker News、OpenStreetMap、Vimeo、Spotify、The Roku Channel、BBC Learning English、OneDrive。同一轮实测确认国内可直连、因此不标的有：squoosh、Carbon、jamovi、Datawrapper、Flourish、WolframAlpha、SageMath Cell、draw.io、regex101、TinyPNG、Photopea、ECharts、Zenodo 等。

二十、常见问题

❓ 编辑器改完保存了，主页刷新没变化？

试试硬刷新（Ctrl + F5），或者先关掉主页标签页再重新打开。如果还不生效，检查一下是不是在浏览器隐身模式下操作（隐身窗口的 localStorage 是隔离的）。

❓ 导入JSON后新加的搜索引擎看不到？

自定义搜索引擎默认是隐藏的。去设置 → 搜索引擎显示，找到它的灰色按钮点一下变蓝就出来了。

❓ 导入后自定义分类消失？

去设置 → 分类显示，看它的按钮是不是灰色的。点蓝就显示。

❓ 怎么只保留我需要的几个分类？

设置 → 分类显示 → 把不要的分类按钮点成灰色，页面和侧边栏就都看不到了。

❓ 我的设置存在哪？

存在浏览器的 localStorage 里。只要不清浏览器数据就一直保留。

❓ 怎么把导航页放到手机桌面？

用手机浏览器打开 https://nav.auroraus.cn → 浏览器菜单 → "添加到主屏幕"/"添加到桌面"。

❓ F1~F12 不灵？

同时按住 Fn，或者在BIOS里把功能键设为标准F1-F12。

二十一、右上角两行：需 VPN / 天气 与 日期时间

🕒 现在是「两行 + 玻璃面板」

首屏右上角是一个圆角的磨砂小块，里面整齐排两行：

  • 第一行：🌐 需 VPN 显示 / 隐藏 开关，右边紧跟 🌙 主题切换。
  • 第二行：日期 · 星期 · 本地时间（如「3月8日 · 周日 · 14:07:33」，每秒走），右边紧跟 🌤️ 天气按钮（正好在 🌙 的正下方）。

  • 两行不会互相遮挡：整块是纵向两行，每行内部横向排列，导航页做过多轮布局校验（含窄屏 640px 断点），行与行、控件与控件都不重叠。

🌤️ 天气按钮会自动显示「你关注的地方」的天气图标

不是固定的太阳图标——它显示的是当前关注地此刻真实的天气 emoji（晴 ☀️ / 多云 ⛅ / 小雨 🌦️ / 雷阵雨 ⛈️ / 雪 ❄️ / 雾 🌫️ …），图标比主题按钮大一号，鼠标悬停能看到「城市 温度° 天气」。

「关注地」的取法：你在天气浮窗里搜索过的城市优先；没设置过就用上次天气缓存里的地点，再没有才按 IP 定位（缓存 12 小时，绝不上报你的精确位置），仍然失败才回落到北京。想固定成某个城市，在天气浮窗底部搜一次即可（之后不会被 IP 定位改掉）。

⚡ 天气是「加分项」，不许拖慢搜索：天气数据每小时最多刷新一次（缓存 1 小时，不必很新），打开页面时先用本地缓存把图标和面板直接画上，网络请求一律等首屏（搜索框 + 站点卡片）画完、主线程空闲后才发，并且每个请求都有硬超时（天气 8s、IP 定位 5s）——外网被墙或很慢时，只会看到「天气获取失败」的提示，搜索和点站点永远不受影响。IP 定位只在确实需要（没有你选过的城市、也没有历史缓存）时才发一次。

🌍 右下角那行图源说明（很浅，但可以点）

用「🌍 地球实况」当壁纸时，首屏右下角会出现一行刻意做得很不显眼的小字（浅灰、半透明，鼠标移上去才变亮变蓝），写两件事：

  • 地球实况时：🌍 图源 国家卫星气象中心（风云四号B 中国区域真彩云图）· 2026-10-17 17:45（北京时间）· 点击去 Zoom Earth 看实时卫星图（选「全球视图」时写「全圆盘真彩 · 更新于 …」）——括号里就是这一帧的观测时间（UTC）——你每次打开都会换成最新的那一帧；取不到气象局数据时会退回 NASA 当日真彩，图源文字会跟着变。
  • 点这一行，一律在新标签页打开 https://zoom.earth/maps/satellite/ —— 也就是「实时卫星图」的原网站，可以在里面自由缩放、切图层、拖时间轴回放。
💡 为什么背景不直接嵌 Zoom Earth 的网页？Zoom Earth 的响应头写着 X-Frame-Options: SAMEORIGIN，浏览器禁止任何第三方站点把它嵌进 iframe（以前那个嵌入版本永远是空白，就是这个原因）。也试过 Himawari 全圆盘（球面视角，中国被压扁在左上方），最终改为 NASA GIBS 的平面（EPSG:4326）真彩色：中国全境方方正正、完整可见。

  • ③ 空气质量（有花粉数据时才多一行「过敏」）：空气质量显示颜色圆点 + 优/良/轻度污染… + AQI + PM2.5；如果能拿到花粉数据，这一段标题会变成「空气与过敏」，多一行过敏（花粉）等级与过敏源（如「高 · 禾本科 60 粒/m³」）。拿不到花粉数据就整行不显示（Open-Meteo 的花粉只在欧洲有观测，国内一般没有，页面不会拿别的数字硬凑）。
  • ④ 穿衣建议：按体感温度给一句（短袖短裤 → 羽绒服），再按风力、降水概率、紫外线补一句提醒（风大加防风外套 / 带伞 / 防晒）。
  • 换城市：浮窗底部输入框打城市名（中文就行，如「杭州」）→ 点搜索；选过的城市会记住，并且从此优先于网络定位，同时首屏天气图标也跟着换。
  • MSN 跳转：底部 🗺️ 地图 打开 MSN 天气地图（带 loc 参数定位到该城市）；MSN 详情 打开该城市的 MSN 预报页（早先那个 /weather/overview 地址已被 MSN 下架，点开会是一堆源码/404，现已换成 /weather/forecast/in-城市名）。
  • 浮窗可以拖：按住标题栏拖动，位置会记住。
